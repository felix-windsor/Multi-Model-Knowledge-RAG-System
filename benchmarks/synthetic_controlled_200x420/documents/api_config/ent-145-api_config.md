## 内容

报表导出接口属于综合管理系统，用于支撑指标采集模块的数据访问。
接口调用前需要通过指标计算服务完成鉴权，返回字段包含日志留存天数。
配置项包括超时时间、重试次数、调用方标识和审计开关。
接口关系：报表导出接口调用指标计算服务，影响日志留存天数。

## 内容

设备状态接口属于物资管理系统，用于支撑日志归档模块的数据访问。
接口调用前需要通过统一身份认证服务完成鉴权，返回字段包含告警闭环率。
配置项包括超时时间、重试次数、调用方标识和审计开关。
接口关系：设备状态接口调用统一身份认证服务，影响告警闭环率。

## 内容

配置下发接口属于数据交换平台，用于支撑报表生成模块的数据访问。
接口调用前需要通过图谱检索服务完成鉴权，返回字段包含异常处置时长。
配置项包括超时时间、重试次数、调用方标识和审计开关。
接口关系：配置下发接口调用图谱检索服务，影响异常处置时长。

- 系统：数据交换平台

- 接口：配置下发接口

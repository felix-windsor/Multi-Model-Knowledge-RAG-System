3. Maintenance and testing

D.Performance. Overall performance of the Gemini telescope is defined as the percentage
of viewable time during which exposures have been taken (i.e. sum of all exposure times
over available time for exposures).
To improve this performance, all possible concurrencies in system operation should be
used. Best use of concurrency occurs when using the Sequencer.

10. Status Source
To support Reversible Lane control in other centers, the
Center shall be able to support the following device
control command for a Reversible Lane:
1. Network identifier (owner of reversible lane)
2. Reversible Lane Identifier
3. Username
4. Password
5. Plan
6. Duration

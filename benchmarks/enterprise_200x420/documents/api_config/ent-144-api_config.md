## 内容

告警推送接口属于安全态势平台，用于支撑设备监控模块的数据访问。
接口调用前需要通过审计日志服务完成鉴权，返回字段包含数据同步延迟。
配置项包括超时时间、重试次数、调用方标识和审计开关。
接口关系：告警推送接口调用审计日志服务，影响数据同步延迟。

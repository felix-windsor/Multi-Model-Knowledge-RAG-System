# 接口配置-设备监控系统-010

- 文档编号：ent-130
- 文档类型：api_config
- 脱敏说明：本文件为合成企业文档样例，不包含真实公司数据。

## 内容

日志查询接口属于设备监控系统，用于支撑告警联动模块的数据访问。
接口调用前需要通过文件转换服务完成鉴权，返回字段包含设备在线率。
配置项包括超时时间、重试次数、调用方标识和审计开关。
接口关系：日志查询接口调用文件转换服务，影响设备在线率。

## 关键实体

- 系统：设备监控系统
- 模块：告警联动模块
- 服务：文件转换服务
- 接口：日志查询接口
- 指标：设备在线率
- 流程：应急响应流程
- 角色：安全管理员角色
